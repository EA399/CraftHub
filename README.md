# CraftHub Launcher

## Download-Link einrichten
1. Neues GitHub-Repository `crafthub-launcher` anlegen und diesen Ordner hochladen.
2. Tag erstellen und pushen:  `git tag v0.1.0 && git push origin v0.1.0`
3. GitHub Actions baut `CraftHub-Setup.exe` und legt sie unter "Releases" ab.
4. Der Download-Link lautet dann:
   https://github.com/DEIN-NAME/crafthub-launcher/releases/latest/download/CraftHub-Setup.exe

## Lokal testen
    npm install
    npm start

Voraussetzung: Java ist installiert (Minecraft startet über das System-Java).
